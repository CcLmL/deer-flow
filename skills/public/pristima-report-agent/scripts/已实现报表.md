# Pristima 已实现报表清单

Pristima Report Server 当前**已实现**的独立报表共 **36 张**（含已精修及尚待精修、完整验收的报表），内部身份以本清单为唯一维护处。

这份清单表示服务当前具备的**导出能力**，**不等于**每个专题都有全部 36 张报表。已精修条目仍以已验证的样本和分支为准；新增条目的“待验收”不影响其已接入状态。

本清单收录当前已开放的 36 个独立主 Format；另 20 个仅登记共用处理器、尚未开放的 Format 变体不计为独立完成报表。`1061/1383` 当前仅实现体温，不包含 Feces Weight；`1061/1761` 当前仅实现 QFC，MEC 尚待实现。

判断某个专题实际能导哪些报表：调用 `GetPTSReportTree`，把本次响应 `checked_all_data`
里的叶子节点与本清单按下面三项内部身份**精确匹配**取交集：

> `report_name` + `rpt_data_type` + `rptformat_id` —— 三项全部相等才算同一张报表

不能只按 `report_name` 或编号大小猜测；清单外的报表视为尚未列入已实现范围，
不替换成名称相近的其他报表。

## 编号复用情况

`rpt_data_type` **不唯一**，同一个值下有多个 Format，必须靠 `rptformat_id` 区分：

- `1001` —— 2 个 Format：`104`（Raw）、`751`（Individual Report-sets）
- `1005` —— 4 个 Format：`112`（Raw）、`174`（Session by Animal）、`175`（Session by Cage）、`429`（Comment）
- `1041` —— 2 个 Format：`533`（Individual Animals by Day）、`220`（Summary by Day / 区间附录）
- `1061` —— 5 个 Format：`1383`（体温）、`1573`（Blood Pressure）、`1575`（ECG）、`1577`（Respiration）、`1761`（QFC）
- `1066` —— 3 个 Format：`300`、`388`、`1742`（均为 Individual Days Seen）
- `1088` —— 2 个 Format：`360`（含个体值）、`361`（按日组汇总）

这也是为什么只能用三项身份取交集：只比 `report_name` 会漏、只比 `rpt_data_type`
会把同一类的多张报表混成一张。
